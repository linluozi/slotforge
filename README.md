# slotforge

`slotforge` reads a Python package, classifies every class as `safe` / `review` /
`unsafe` / `already-slotted`, rewrites the safe ones to use `__slots__`, adds
pickle-compatibility shims, and certifies the change on two measured axes (live
heap and peak RSS); the layout estimate is an internal helper, not the headline.
Every edit can be rolled back byte-for-byte. This repository
also contains three real patches generated by the tool against voluptuous, parse
and deepmerge, with their upstream test suites green after the change.

Upstream: none (original tool; the three patch targets are attributed below).

## 本轮创新

**新在哪**：把 `__slots__` 从「静态建议」做成「测量 → 自动改写 → 回滚」闭环，
并第一次在同一批真实上游类上同时给出两轴实测：tracemalloc 活跃堆、
100 万实例峰值 RSS（布局估算只作内部对照，不作为卖点）。**和谁不一样**：`linluozi/slotfit` 只读扫描并给建议，不写一行
上游代码；经典 `-opt-lab` 只改热路径、只报加速比。**凭什么推翻旧结论**：slotfit
对「纯标量属性」测得每实例可省 50–84%；本仓库把同一变化放到 12 个真实类上做
端到端测量（活跃堆 + 1M 峰值 RSS 两轴；布局只作内部对照），**活跃堆中位只省
24.5%、峰值 RSS 中位只省 21.0%**，8 个类的活跃堆
收益低于 35%，因为实例引用的编译产物/元组/列表把收益吃掉了。也就是说：
**`__slots__` 的布局收益不等于端到端内存收益**，这正是以前没人量化的那一半。

| [r1chardj0n3s/parse](https://github.com/r1chardj0n3s/parse) | `23ee37e87fced1d59d9e12d75cc6d934ed89b72e` | MIT | Result, Match, int_convert, convert_first | `patches/parse.patch` (32+ / 0−) | 184 passed, 1 skipped |
| [toumorokoshi/deepmerge](https://github.com/toumorokoshi/deepmerge) | `5be8369aa91213c67aa241e4fba7e5a41b29da22` | MIT | Merger, StrategyList | `patches/deepmerge.patch` (16+ / 0−) | 45 passed |

`patch.diff` at the repository root is the concatenation of the three files.
Apply one upstream's part with a path filter from that upstream's clone root:

```bash
git apply --check --include='parse/*' patch.diff
```

The pickle shims are part of the generated patch: without them CPython 3.12
refuses to pickle a class that defines `__slots__` but not `__getstate__`
(`copyreg` raises `TypeError`). The shim returns a plain dict, so a pickle
written by the old dict layout loads into the new slotted class.

**The 35% memory target was not met on the end-to-end metric.** The nightly plan
set 35% per instance; live heap (median 24.5%) and RSS (median 21.0%) both fall
short, and 8 of the 12 classes save less than 35% of live heap. This repository is
named and framed as an audit/rewrite tool, not an `-opt-lab`, and does not claim a
35% end-to-end win.

## Differential

`benchmark/diffcheck.py` builds 2,000 distinct argument combinations per class
(24,000 instances per implementation), normalises every attribute into a
canonical state tuple, and hashes the state stream. Deduplication is by
`sha256(repr(state))`; the table reports **distinct** states, not loop count.

| class | distinct states | state equal | pickle round-trip | deepcopy round-trip |
|---|---:|---|---:|---:|
| `Schema` | 2000 | yes | 0/2000 both (closure payload) | 2000/2000 |
| `Msg` | 2000 | yes | 0/2000 both | 2000/2000 |
| `Range` | 2000 | yes | 2000/2000 | 2000/2000 |
| `Coerce` | 2000 | yes | 2000/2000 | 2000/2000 |
| `DefaultTo` | 2000 | yes | 0/2000 both (closure payload) | 2000/2000 |
| `Replace` | 2000 | yes | 2000/2000 | 2000/2000 |
| `Result` | 2000 | yes | 2000/2000 | 2000/2000 |
| `Match` | 2000 | yes | 0/2000 both (`re.Match`) | 2000/2000 |
| `int_convert` | 30 | yes | 2000/2000 | 2000/2000 |
| `convert_first` | 2 | yes | 2000/2000 | 2000/2000 |
| `Merger` | 8 | yes | 2000/2000 | 2000/2000 |
| `StrategyList` | 256 | yes | 2000/2000 | 2000/2000 |
| **total** | **16,296** | **0 mismatches** | counts unchanged | unchanged |

`Result` pickles are byte-identical between the dict and slotted layouts
(`pickle_samples_b64` equality, checked in `evidence/diff-parse-*.json`), which
is the point of the dict-returning `__getstate__` shim.

## Gates (all commands are runnable as written)

- **G1 · upstream suites green.** Baseline counts were identical; after patch:
  `pytest voluptuous/tests -q` → 223 passed; `pytest -q` (parse, with its own
  `--cov --doctest-modules` addopts) → 184 passed, 1 skipped; `pytest deepmerge
  -q` → 45 passed. 0 failed in all three.
- **G2 · differential.** 16,296 distinct states, 0 state mismatches; 24,000
  instances per side; canonical SHA-256 streams equal per library. Raw JSON:
  `evidence/diff-{voluptuous,parse,deepmerge}-{baseline,optimized}.json`.
- **G3 · memory.** Live-heap median 24.5%, min 8.0% — **below the 35% target**;
  reported as a measured negative, not a win. RSS is lower on all 7 measured
  classes (7.1%–36.4%).
- **G4 · throughput.** median 1.085x, min 1.001x; every class ≥ 0.98x.
  Warmup 3, 5 timed runs, `time.perf_counter`, 50,000 constructions per run.
- **G5 · RSS not worse.** 7/7 classes lower (table above); no regression.
- **Rollback.** `apply()` writes a sibling `.slotforge.bak`; `rollback()`
  restores byte-for-byte. `tests/test_slotforge.py::test_patch_and_rollback_byte_identical`.

## Reproduce

```bash
python3 -m venv .venv && . .venv/bin/activate && pip install -e . pytest
python3 -m pytest -q                       # 9 passed: scanner, rewrite, rollback, pickle, CLI, differential
python3 benchmark/bench.py --root /tmp/voluptuous-src --lib voluptuous --n 1000000 --impl optimized --out /tmp/optimized.json
```

To reproduce a patch (network rule of the runner: SSH clone; replace with HTTPS
elsewhere):

```bash
git clone --depth=1 https://github.com/r1chardj0n3s/parse.git /tmp/parse-src
cd /tmp/parse-src && git apply --check /path/to/slotforge/patches/parse.patch
git apply /path/to/slotforge/patches/parse.patch && python -m pytest -q
```

## Environment

AMD EPYC 7K62, 4 vCPU, 3,723 MiB RAM; CPython 3.12.3 (`/usr/bin/python3`);
pytest 9.2.0; Linux. No RNG: the differential uses sample index `i` as the
deterministic seed; the benchmark constructs fixed-argument instances. Only
CPython 3.12 is installed on this machine, so 3.10/3.11 cross-runs were not
performed. Throughput differences are within a few percent and are not a
speedup claim.

## Known limits

- The rewrite only handles classes with object-only bases, no decorators, and
  all attributes assigned in `__init__`; everything else is classified (and
  skipped) rather than guessed.
- Adding `__slots__` removes `__dict__`/`__weakref__`; the scanner flags source
  that uses them, but a library can still rely on dynamic attributes indirectly
  (e.g. an external plugin). Run the upstream suite after applying the patch.
- Pickle compatibility is preserved with a dict-returning shim. Classes whose
  state contains an unpicklable payload (closures, `re.Match`) were unpicklable
  before and after; that is recorded, not hidden.
- The patches are pinned to the commits above; they may need a rebase on newer
  upstream heads.
